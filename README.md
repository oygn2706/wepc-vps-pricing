## 关于中转的那些事

WePC官网在好几个机房描述里都提到"建议中转"或"必须中转"，这里解释一下。中转指的是在国内用户和海外VPS之间加一层中转节点，用来优化回程线路、降低延迟。WePC自己也提供中转服务，比如沪日专线中转、台湾中转等，价格从29.9澳元/月起。

如果你是电信用户，选日本、新加坡、台湾这些机房的时候，大概率需要搭配中转才能有流畅的直播体验；联通和移动用户在大部分亚洲机房可以直连，体验差异没那么大。这部分成本要算进总预算里，别只看VPS本身的WePC VPS价格就以为完事了。
